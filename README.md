# Larkbase Analysis Reports

这是一个包含各种公司分析报告的项目，主要收集和整理了不同行业和领域的企业分析文档。

## 项目内容

本项目包含以下类型的分析报告：

- **企业分析报告**：对不同公司的深度分析和评估
- **行业分析**：各个行业的发展趋势和竞争格局分析
- **投资分析**：投资机会和风险评估报告
- **市场研究**：市场动态和消费者行为分析

## 文件结构

```
larkbase/
├── README.md                    # 项目说明文档
├── .gitignore                   # Git忽略文件配置
└── report/                      # 分析报告目录
    ├── *.md                     # 各公司分析报告（Markdown格式）
    ├── 分析报告汇总.xlsx          # 所有报告的汇总表格
    └── generate_report_excel.py  # 生成Excel汇总的Python脚本
```

## 主要功能

- 提供系统化的企业分析框架
- 支持多格式报告存储和管理
- 包含自动化报表生成工具
- 便于查阅和比较不同企业的发展状况

## 使用说明

1. 查看具体公司分析：进入 `report/` 目录，找到对应企业的Markdown文件
2. 查看汇总信息：打开 `分析报告汇总.xlsx` 文件
3. 生成新的汇总：运行 `generate_report_excel.py` 脚本
